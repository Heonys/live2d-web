# live2d-web v0.3.1 안정화 기준선 — 2026-08-24

0.4 기능 개발 전에 공개 패키지·소비자 검증·브라우저 동작·smoke 성능의 현재
상태를 고정한다. 패키지와 성능 수치는 로드맵 문서에서 복사하지 않고
`develop`의 코드 기준 커밋 `1a2b84ba3b8e5b6d4f00e30a490224c0405dba13`에서
다시 측정했다.

## 공개 패키지

공개 subpath는 `.`, `/react`, `/backends/cubism-webgl` 세 개다. 개발 저장소의
`/backends/pixi-v6`는 npm tarball에 포함하지 않는다.

`pnpm verify:package`의 `npm pack --dry-run` 결과:

- 파일 수: **31**
- tarball 압축 크기: **124.8 kB**
- 해제 크기: **664.8 kB**

tsdown이 출력한 JavaScript 파일별 크기는 다음과 같다. 공유·동적 chunk가 있어
이 숫자를 단순 합산한 값을 모든 소비자의 실제 초기 다운로드 크기로 해석하지
않는다.

| 역할 | emitted 파일 | raw | gzip |
| --- | --- | ---: | ---: |
| root entry | `index.mjs` | 0.68 kB | 0.34 kB |

entry 경계를 먼저 맞추고 raw·gzip을 함께 비교한다.

실제 tarball 소비자 버전은 Vite `8.1.5`, React/React DOM `19.2.8`, Next

[호환성 문서](../compatibility.md)에 분리했다.

CI는 `main`과 향후 원격 `develop` push에서 lint·typecheck·unit·package 검증과
Playground build를 실행한다. 브라우저 e2e는 이 기준일에 **로컬 수동 검증**이며
CI나 릴리스의 자동 게이트가 아니다. Hiyori와 Cubism Core는 Git, Actions cache,
artifact에 넣지 않는다. 자산 사용 조건은
[Free Material License Agreement](https://www.live2d.com/eula/live2d-free-material-license-agreement_en.html)와
[Proprietary Software License](https://www.live2d.com/eula/live2d-proprietary-software-license-agreement_en.html)를
따른다.

## smoke 성능과 자원 정리

production Playground의 600×600 CSS Stage, resolution 1, Stage 1개에서 Mark와
Hiyori를 각각 10초씩 한 번 측정했다. warm-up은 0초다.

| 모델 | ready/first draw | frame p95 | 33ms 초과 | dispose 뒤 소유 자원 |
| --- | ---: | ---: | ---: | --- |
| Mark | 125.8 ms | 17.6 ms | 0.00% | 모두 0 |
| Hiyori | 113.7 ms | 17.6 ms | 0.17% | 모두 0 |

"모두 0"은 Canvas, WebGL context, texture, Framework reference, pending motion,
pending expression의 개수가 모두 0임을 뜻한다. smoke 테스트의 현재 차단 조건은
초당 30개보다 많은 frame sample, first draw 존재와 모든 소유 자원 정리다.
ready·frame p95·33ms 초과 비율은 이번 기준선부터 회귀 비교 대상으로 기록하지만
아직 고정된 자동 실패 임계값은 없다.

이 실행의 WebGL renderer는 `ANGLE ... SwiftShader`다. 따라서 수치는 같은
headless 환경에서 큰 회귀를 찾는 개발 기준선이며 실제 Apple GPU, 모바일 GPU,
OBS 또는 사용자 장치의 성능으로 일반화하지 않는다. 실제 하드웨어 기준은
별도의 hardware benchmark와 반복 측정으로 관리한다. raw 결과는 ignored
`benchmark-results/model-smoke.latest.json`에 생성되며 Git이나 npm 패키지에
포함하지 않는다.
