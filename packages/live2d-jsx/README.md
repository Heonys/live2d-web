# live2d-web

Vanilla-first Live2D with optional React bindings. See the
[project README](https://github.com/Heonys/live2d-jsx#readme) for API,
installation, development and licensing details.

The root entry is React-free. React components are exported from `/react`, and
the temporary PixiJS v6 comparison backend is exported from
`/adapters/pixi-v6`.

This package does not include Live2D Cubism Core, Cubism Framework, shaders or
sample models. It also does not include a wLipSync calibration profile.
