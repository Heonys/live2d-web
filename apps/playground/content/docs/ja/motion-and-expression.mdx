## 再生結果とフェード

motion() は単純な Promise&lt;void&gt; を維持します。完了・中断・skip・dispose を区別する場合は playMotion() を使います。sequence は最初の非完了結果で停止します。

```ts
const result = await character.playMotion('TapBody', 0, {
  fadeInMs: 250,
  fadeOutMs: 400,
})

await character.sequence([
  { group: 'TapBody', index: 0 },
  { group: 'Idle', index: 0 },
])

await character.expression('smile', { fadeInMs: 500 })
```

## 制作者の既定値を維持

fade を省略すると model3・motion3・exp3 の設定を保ちます。motion3 のパラメータ別 fade は再生全体の上書きより優先されます。
