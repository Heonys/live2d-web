## 오류 코드부터 확인

`Live2DError`에는 안정적인 code와 자산 오류의 URL·asset type·HTTP 상태가
있습니다. 이 값과 브라우저·모델 export 버전을 이슈에 적되 라이선스 자산은
첨부하지 마세요.

### browser-only

**원인:** SSR·Node 또는 필요한 DOM이 없는 Worker에서 브라우저 API를
호출했습니다. **확인:** stack에서 첫 `createLive2D()` 또는 DOM 의존 호출을
찾습니다. **수정:** client mount 뒤에 호출하고 Next.js에서는 Client
Component에서 `/react`를 import합니다. **재시도:** 브라우저 문맥으로 옮기기
전에는 불가능합니다.

### core-missing

**원인:** `coreUrl`의 Cubism Core를 불러오지 못했고 호환되는 전역 Core도
없습니다. **확인:** script 요청·CSP·CORS·Core 5.3 URL을 봅니다. **수정:** 공식
Core를 self-host하고 접근 가능한 URL을 전달합니다. **재시도:** 경로나 정책을
고친 뒤 가능합니다.

### webgl-unsupported

**원인:** 브라우저가 WebGL2 context를 만들지 못했습니다. **확인:** WebGL2
지원·하드웨어 가속·활성 context 개수를 봅니다. **수정:** 지원 브라우저/GPU를
사용하거나 다른 Canvas를 정리합니다. **재시도:** 환경이 바뀐 뒤에만 유효합니다.

### invalid-props

**원인:** API 인자나 옵션이 문서의 형태·범위를 벗어났습니다. **확인:** 오류
메시지에 나온 필드를 봅니다. **수정:** 호출 값을 고칩니다. **재시도:** 같은
값으로는 해결되지 않습니다.

### invalid-tree

**원인:** React component가 필요한 provider 밖에 있거나 하나의 Canvas를 둘
이상의 모델이 소유합니다. **확인:** `Live2DCanvas`와 `Live2DModel` 주변 트리를
봅니다. **수정:** Canvas 하나 아래 모델 하나를 두고 hook을 해당 provider 안에서
사용합니다. **재시도:** 트리를 바꾸기 전에는 불가능합니다.

### lipsync-error

**원인:** 선택형 립싱크의 준비 또는 처리가 실패했습니다. **확인:** secure
context·마이크 권한·AudioContext 상태·wLipSync profile을 봅니다. **수정:** 사용자
gesture에서 audio를 resume하거나 volume driver를 사용합니다. **재시도:** audio
설정을 고친 뒤 가능하며 모델 렌더링은 계속될 수 있습니다.

### tracking-error

**원인:** MediaPipe 초기화·추론·Worker protocol 또는 정리가 실패했습니다.
**확인:** optional peer, WASM/task 경로, CORS, CSP `worker-src`, timeout과 브라우저
지원을 봅니다. **수정:** 자산/Worker 설정을 고치고 Worker 미지원이면 main
execution을 선택합니다. **재시도:** 원인을 고친 뒤 tracker를 새로 만듭니다.

### model-load-failed

**원인:** model3 또는 참조 자산에 HTTP 오류·CORS 차단·누락·parse 실패가
있습니다. **확인:** `details.url`, `assetType`, `httpStatus`와 Network panel을
봅니다. 404는 잘못된 URL/경로, status 없는 fetch 실패는 주로 CORS/network,
parse 메시지는 손상되거나 호환되지 않는 export입니다. **수정:** 대소문자를 포함한
모든 참조 파일과 MIME/CORS header를 바로잡거나 모델을 다시 export합니다.
**재시도:** 일시적 network 오류 또는 자산 수정 뒤 가능합니다.

### render-error

**원인:** 준비 뒤 렌더링이 중단됐으며 흔한 원인은 WebGL context loss입니다.
**확인:** 첫 console/driver 오류와 GPU context 수를 봅니다. **수정:** GPU 부담을
줄이고 Canvas 오류 화면의 retry를 실행합니다. **재시도:** 가능하며 stage 옵션을
유지한 채 다시 만듭니다.

### adapter-error

**원인:** backend가 미지원 capability를 거부했거나 다른 backend의 handle을
받았습니다. **확인:** backend 이름과 옵션 지원표를 봅니다. **수정:** 기본 backend를
사용하거나 미지원 옵션을 제거하고 custom adapter를 갱신합니다. **재시도:** 설정을
바꾸기 전에는 해결되지 않습니다.
