## 오류 코드부터 확인

Live2DError에는 안정적인 code와 자산 오류의 URL·asset type·HTTP 상태가 있습니다. 이 값과 브라우저·모델 export 버전을 이슈에 적되 라이선스 자산은 첨부하지 마세요.

- model-load-failed: URL·HTTP 상태·CORS를 확인합니다.
- core-load-failed: Core URL과 Core/Framework 조합을 확인합니다.
- invalid-props: 호출 값을 고칩니다. 재시도로 해결되지 않습니다.
- tracking-error: optional peer·WASM/model 경로·Worker CSP를 확인합니다.
