## 볼륨 드라이버

`createVolumeLipSync()`는 앱이 측정한 RMS 값을 부드러운 입 벌림 값으로 바꿉니다. 마이크 권한, AudioContext, 오디오 노드, `requestAnimationFrame`은 앱에서 직접 관리합니다.

```ts
import { createVolumeLipSync } from 'live2d-web'

const driver = createVolumeLipSync()
const detach = character.addLipSync({ driver })

// The app owns AudioContext, RMS calculation and scheduling.
driver.sample(rms, elapsedMs)

detach()
```

## 입력 충돌 피하기

얼굴 트래킹과 마이크 립싱크를 함께 사용한다면 트래커의 `mouth` 채널을 끄세요. 두 기능이 같은 입 파라미터를 동시에 바꾸는 문제를 피할 수 있습니다. wLipSync를 사용하려면 브라우저가 AudioWorklet을 지원해야 합니다.
