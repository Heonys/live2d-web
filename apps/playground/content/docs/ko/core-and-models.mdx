## Cubism Core

내장된 Framework 5-r.5 어댑터는 Cubism Core 5.3을 사용합니다. `coreUrl`을 지정해 라이브러리가 불러오게 하거나, 앱 코드보다 앞서 `<script>`로 로드하세요. Cubism Core는 npm 패키지나 공개 이슈의 첨부 파일로 배포하면 안 됩니다.

```html
<script src="/live2dcubismcore.min.js"></script>
```

## 모델 디렉터리

Cubism Editor에서 내보낸 디렉터리 구조를 그대로 유지하세요. 모델은 moc3, 텍스처, 모션, 표정, 물리 연산, pose, user-data 파일을 참조할 수 있습니다.

- `model3.json`이 가리키는 상대 경로와 파일명의 대소문자를 바꾸지 마세요.
- 텍스처나 모션을 다른 출처에서 제공한다면 CORS를 설정하세요.
- 렌더링 문제를 찾기 전에 Inspector로 모델 구성부터 확인하세요.

## 자산을 안정적으로 제공하기

버전이 붙은 모델 파일은 가능하면 같은 origin의 고정 URL에서 제공하세요. 다른 origin을 사용한다면 model3, moc3, 텍스처, 모션, 표정 파일에 `GET`과 CORS를 허용해야 합니다.

```text
public/
├─ live2dcubismcore.min.js
└─ models/avatar/
   ├─ avatar.model3.json
   ├─ avatar.moc3
   ├─ textures/
   └─ motions/
```

## 렌더링 전에 호환성 확인하기

[Inspector](/ko/inspect)나 `inspectModelSource()`로 누락 파일, 외부 URL, 지원하지 않는 버전을 먼저 확인하세요. 공개 이슈에는 Core나 모델 파일 대신 오류 코드, 실패 URL, HTTP 상태, export 버전을 남기세요.
