## 렌더링 전에 검사

> 모델 검사 API는 실제 프로젝트 사용 사례와 다음 마이너 버전의 호환성을 충분히 확인할 때까지 **experimental**로 제공합니다.

`live2d-web/inspect`는 React, Cubism Core, Framework, MediaPipe, JSZip을 불러오지 않고 `model3.json`이 참조하는 파일을 검사합니다. 모델 내용의 문제는 `findings`에 모아 반환하며, 잘못된 API 인자나 중단 요청만 `Promise`를 거부합니다.

```ts
import {
  inspectModelCapabilities,
  inspectModelSource,
} from 'live2d-web/inspect'

const report = await inspectModelSource({
  src: 'https://example.com/model.model3.json',
})

if (report.status === 'compatible') {
  console.log(report.motions, report.expressions)
}
```

URL로 검사하면 모델에 적힌 HTTP(S) 참조를 실제로 요청합니다. 브라우저에서는 CORS가 적용되지만 Node 서버에는 브라우저와 같은 CORS나 사설망 접근 차단이 없습니다. 서버가 신뢰할 수 없는 모델 URL을 받는다면 허용할 호스트 목록과 네트워크 정책을 앱에서 반드시 적용하세요. 라이브러리는 서버가 접근해도 되는 사설 IP 범위를 알 수 없습니다. 로컬 파일 연결자를 사용하는 검사는 압축 파일에 적힌 외부 URL을 요청하지 않습니다.

## 브라우저 ZIP 검사기

Inspector는 ZIP 파일을 현재 브라우저 탭 안에서만 엽니다. 파일 크기, 개수, 경로, 모델 참조를 확인하며 업로드하거나 저장하지 않고 사용 정보도 전송하지 않습니다. 호환되지 않는 압축 파일은 모델로 렌더링하지 않습니다.
